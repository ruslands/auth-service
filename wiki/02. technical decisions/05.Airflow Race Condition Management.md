### Airflow Race Condition Management

#### Problem
Race conditions can occur when multiple Airflow tasks compete for limited resources. This is particularly common when several DAGs use the same service account or hit API rate limits simultaneously.

#### Solution
Create and use Airflow pools to control concurrency:

1. In Airflow UI, go to Admin → Pools and create a new pool (e.g., `google_pool`)
2. Apply the pool to relevant operators:

```python
PythonOperator(
    task_id="job_wrapper_runner",
    python_callable=job_wrapper("jobs.some_job.main.lambda_handler"),
    pool="google_pool",  # Controls access to shared resources
)
```
