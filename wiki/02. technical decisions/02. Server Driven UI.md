# Server Driven UI

Поведением столбцов в таблице управляет backend
Есть несколько допустимых значений столбцов

- text
- image
- datetime
- url
- integer
- chart
- qr_code
- enum
- boolean

* url 
На фронт передается объект

{
    "url": <url>,
    "title": <title>
}
или 
{
    "url": EMPTY_VALUE,
    "title": EMPTY_VALUE
}

* text
Для колонки типа "text" с available_values передаем "key"

* enum
Для колонки типа "enum" при обновлении передаем "value"
