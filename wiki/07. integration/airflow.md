

### Variables
It's required to save the following variables in the Airflow Variables:
- YANDEX_SECRET_ID
- YANDEX_AUTHORIZED_KEY_ID
- YANDEX_PRIVATE_KEY_BASE64
- YANDEX_SERVICE_ACCOUNT_ID

These variables are used to authenticate with Yandex Cloud and access the necessary resources for the Airflow tasks. Make sure to set them up correctly in your Airflow environment.
These variables saved in Postgres Database which managed by Airflow.
